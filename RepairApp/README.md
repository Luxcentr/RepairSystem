# Система учета ремонта техники

Приложение на C# для учета заказов на ремонт.

## Возможности
- Добавление, редактирование, удаление заказов
- Изменение статуса: Новый -&gt; В ремонте -&gt; Ожидание запчастей -&gt; Готово
- Хранение данных в JSON
- REST API
- Веб-интерфейс

## Стек
- C#, ASP.NET Core Web API
- System.Text.Json
- HTML + JavaScript

## Запуск
1. dotnet run
2. Открыть http://localhost:5000/index.html
